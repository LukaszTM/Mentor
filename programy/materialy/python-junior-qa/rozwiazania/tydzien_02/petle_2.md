# Rozwiązanie — ćwiczenie 2 (samodzielne) — Pętle for i while, range, break i continue

Najpierw własna próba. Podpowiedzi odkrywaj po kolei.

## Podpowiedź 1
Wypisz kolejne wartości x na kartce.

## Podpowiedź 2
Warunek != 0 omija zero przy kroku 2.

## Podpowiedź 3
Porównanie > działa dla każdej liczby.

## Rozwiązanie
(1) nie — pętla nieskończona; (2) `while x > 0:`; (3) wypisze 3, 1, -1 (po -1 warunek fałszywy).

## Oczekiwany wynik
(1) nie — x: 3, 1, -1, -3… nigdy nie równa się 0; (2) while x > 0:; (3) 3, 1, -1.
