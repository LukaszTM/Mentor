# Rozwiązanie — ćwiczenie 1 (prowadzone) — Git w zespole: gałęzie, diff, log, cofanie zmian i pull request

Najpierw własna próba. Podpowiedzi odkrywaj po kolei.

## Podpowiedź 1
Najpierw gałąź, potem praca na niej.

## Podpowiedź 2
Wysyłasz zacommitowane zmiany.

## Podpowiedź 3
Po scaleniu aktualizujesz lokalne main.

## Rozwiązanie
2 (gałąź) → 4 (commit) → 1 (push) → 3 (merge PR) → 5 (main + pull).

## Oczekiwany wynik
2, 4, 1, 3, 5.

## Wyjaśnij własnymi słowami
