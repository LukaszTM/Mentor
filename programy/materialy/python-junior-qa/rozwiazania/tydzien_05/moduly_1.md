# Rozwiązanie — ćwiczenie 1 (prowadzone) — Podział kodu na moduły i import własnych plików

Najpierw własna próba. Podpowiedzi odkrywaj po kolei.

## Podpowiedź 1
Import konkretnej nazwy: from … import ….

## Podpowiedź 2
Zaimportowana nazwa działa bez przedrostka.

## Podpowiedź 3
Po import modułu: moduł.funkcja().

## Rozwiązanie
(1) `from ceny import brutto`; (2) `brutto(10)`; (3) `ceny.brutto(10)`.

## Oczekiwany wynik
(1) from ceny import brutto; (2) brutto(10); (3) ceny.brutto(10).

## Wyjaśnij własnymi słowami
Dlaczego to działa? Co się zmieni, gdy zmienisz jedną daną (granicę, typ, plik)?
