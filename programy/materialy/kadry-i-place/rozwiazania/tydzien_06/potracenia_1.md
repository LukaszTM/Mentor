# Rozwiązanie — ćwiczenie 1 (prowadzone) — Potrącenia z wynagrodzenia: art. 87–91 KP
Plik startowy: `cwiczenia/tydzien_06/potracenia_1.md`

Zasada: najpierw własna próba. Podpowiedzi odkrywaj po kolei — rozwiązanie dopiero na końcu.

## Podpowiedź 1 — pytanie naprowadzające
Czy kwota wolna 3 605,85 jest „dla wszystkich”? Co zmienia PPK pracownika?

## Podpowiedź 2 — gdzie szukać
Demonstracja, krok 4; Warsztat → Potrącenia: Netto 3893.29, inne, zajęcie 1200, PPK 2.

## Podpowiedź 3 — częściowy przykład
Szkic: 1/2 × 3 893,29 = 1 946,65; wolna 3 501,73; 3 893,29 − 3 501,73 = 391,56; min(1 946,65; 391,56; 1 200) = …

## Pełne rozwiązanie
```
Granica (art. 87 §3 pkt 2): 1/2 netto = 1 946,65.
Kwota wolna (art. 87¹ §1 pkt 1): 100% minimalnego netto dla parametrów pracownika: 4 806, KUP 250, PIT-2, PPK 2%/1,5% → 3 501,73.
Potrącenie = min(1 946,65; 3 893,29 − 3 501,73 = 391,56; zajęcie 1 200) = 391,56 zł → do komornika w dniu wypłaty (10.12); pracownikowi zostaje 3 501,73.
Odpowiedź komornikowi (7 dni, art. 882 KPC): „W odpowiedzi na zajęcie z dnia … informujemy: wynagrodzenie netto pracownika za ostatnie 3 miesiące wyniosło …/…/… zł; możliwa miesięczna kwota potrącenia z uwzględnieniem kwoty wolnej wynosi ok. 390 zł; brak innych zajęć i alimentów; wynagrodzenie płatne do 10. dnia następnego miesiąca.”
```

## Oczekiwany wynik
granica 1/2 × 3 893,29 = 1 946,65; kwota wolna (minimalne netto z PPK 2%) = 3 501,73; netto − wolna = 391,56 → potrącenie 391,56 (nie 1 200 — reszta zaległości czeka); zostaje 3 501,73; odpowiedź: wynagrodzenie z 3 miesięcy, brak innych zajęć, miesięczna kwota możliwa ~390 zł.
