# AGENTS.md — Pod Lipą (kurs vibe coding)

## Projekt
Narzędzia dla agroturystyki „Pod Lipą”: kalkulator ceny, lista gości, walidacja formularza, kalendarz pokoi. Dane fikcyjne.

## Polecenia
- testy: `python -m pytest -q`
- uruchomienie: `python <plik>.py`

## Zasady
- Najpierw plan w punktach; zmiany dopiero po akceptacji.
- Jedna funkcja na zmianę; po zmianie uruchom testy.
- Nie zmieniaj testów, żeby przeszły — opisz, jeśli test wydaje się błędny.
- Nie dodawaj zależności bez pytania.
- Komentarze po polsku; input() tylko w bloku __main__.
