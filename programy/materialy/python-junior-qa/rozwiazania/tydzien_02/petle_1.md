# Rozwiązanie — ćwiczenie 1 (prowadzone) — Pętle for i while, range, break i continue

Najpierw własna próba. Podpowiedzi odkrywaj po kolei.

## Podpowiedź 1
Akumulator suma = 0 przed pętlą.

## Podpowiedź 2
Licznik zer: if ilosc == 0: zera += 1.

## Podpowiedź 3
range(start, stop, krok) — stop nie wchodzi.

## Rozwiązanie
120 + 0 + 80 + 0 + 35 = 235; zera: 2; range(2, 10, 3) → 2, 5, 8 = 3 obroty.

## Oczekiwany wynik
(1) 235; (2) 2; (3) 3 obroty (2, 5, 8).

## Wyjaśnij własnymi słowami
Dlaczego to działa? Co się zmieni, gdy zmienisz jedną daną (granicę, typ, plik)?
