# Rozwiązanie — ćwiczenie 1 (prowadzone) — GitHub: konto z 2FA, repozytorium prywatne i wysyłanie zmian

Najpierw własna próba. Podpowiedzi odkrywaj po kolei.

## Podpowiedź 1
Najpierw bezpieczeństwo konta.

## Podpowiedź 2
Remote możesz dodać, gdy repozytorium na GitHubie istnieje.

## Podpowiedź 3
Git for Windows ma menedżer logowania.

## Rozwiązanie
2FA → repo na GitHubie → remote add → push = DBCA. Logowanie w przeglądarce, nie hasło w terminalu.

## Oczekiwany wynik
DBCA; w oknie przeglądarki (Git Credential Manager).

## Wyjaśnij własnymi słowami
Dlaczego to działa? Co się zmieni, gdy zmienisz jedną daną (granicę, typ, plik)?
