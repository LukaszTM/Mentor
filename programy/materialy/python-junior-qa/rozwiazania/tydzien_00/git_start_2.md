# Rozwiązanie — ćwiczenie 2 (samodzielne) — Git i GitHub — pierwszy commit i push

Najpierw własna próba. Podpowiedzi odkrywaj po kolei.

## Podpowiedź 1
Commit zapisuje tylko to, co jest w poczekalni.

## Podpowiedź 2
push wysyła, commit zapisuje lokalnie.

## Podpowiedź 3
Historia pamięta każdą poprzednią wersję.

## Rozwiązanie
(1) nie; (2) nie; (3) nie — usunięcie pliku nowym commitem nie usuwa go z poprzednich commitów. Hasło, które trafiło do repozytorium, trzeba natychmiast zmienić.

## Oczekiwany wynik
(1) nie — bez git add zmiana nie jest w poczekalni; (2) nie — commit jest tylko lokalnie; (3) nie — hasło zostaje w historii, trzeba je zmienić.
